# svetlanatbaytarliq.com

Website of Svetlana-T Baytarlıq Klinikası (AZ / RU / EN).
The source page is `src/base.html` (texts, services, products, CONFIG block). Photos go in `images/`.
After editing it run `python3 make_v2.py && python3 build.py` — that writes the live `index.html` (3D anatomy, red/black/white theme) and the `/ru/` and `/en/` pages. Don't edit `index.html` directly.
